# D-SHIFT v1.0.0 — research integration baseline

First versioned weight release for **Distilled Spatial-context Hybrid Inference
with Freshness-aware Tracking**. This freezes existing work; it is not a new
training run, an autonomous flight release, or competition qualification.

## Selected models

- Goal: **Context-16K FP32**, 16,183 parameters, with the matching Keras checkpoint
  and INT8 comparison export.
- Balloon: **Tiny-6K INT8**, 6,131 parameters, with its Keras checkpoint. This is a
  separately validated baseline; combined balloon/goal operation is not qualified.
- Runtime: isolated Linux ARMv6/VFPv2 TensorFlow Lite 2.20.0 C API build. It does
  not replace the Pi system library and is not executable on macOS.

## Downloads

- `d-shift-v1.0.0-weight-lineage.zip`: seven selected Keras stage checkpoints
  covering the imported ImageNet backbone, initial goal/balloon teachers,
  proposal-adapted teachers, and distilled students, plus three TFLite exports,
  original provenance, configs, epoch logs, and model documentation.
- `d-shift-v1.0.0-armv6-runtime.zip`: measured runtime, build receipt, and upstream
  license notices.
- `SHA256SUMS`: checksums for both archives. The committed model manifest also
  checks every archive member.

Small student weights and their metadata are already in the repository at
`models/v1.0.0/`. See `docs/MODEL_V1.md` for the model card, reproduction limits,
configuration, download instructions, and documented full lineage.

Datasets, images, annotations, cached teacher logits, recordings, intermediate
epoch checkpoints, optional YOLO weights, and the standalone pixel implementation
are excluded. This preserves the selected end-to-end weight chain, not every
experimental training state. No original weights or historical approval flags
were modified.

## Verification before publication

- 237 Python tests passed, two skipped; seven JavaScript tests passed; Ruff passed.
- Thirty committed artifact files, 105 source files, and both release archives
  passed manifest checks at packaging time.
- All seven archived Keras checkpoints loaded and produced finite generated-probe outputs.
- All three TFLite exports loaded and produced finite normalized scores.
- Goal FP32 probe maximum score difference versus Keras: approximately 6.1e-9.
- INT8 probes are not asserted bit-equivalent to FP32; balloon's generated probe
  maximum score difference was approximately 0.0386. Historical device parity
  compares the same quantized export between platforms, not INT8 against FP32.

These are packaging/software checks, not fresh Pi measurements or detection
accuracy. No camera, SSH session, motor command, or new dataset evaluation was
used to create this release.

## Known limitations

Small/orange goal localization remains weak. Public development scenes were
reused for model selection. The goal branch's 7.93 FPS paced replay and 3.31 FPS
desk-camera figures have different evidence scopes and do not qualify arena
performance. The later camera rotation correction has smoke verification only.
Balloon full-frame false positives remain significant. All deployment approval
flags remain false, and inference requires explicit research opt-in.
