Pixel-to-angle mapping

Waiting for the camera model

Hover or touch either grid to compare the same pixel and ray. The blue marker shows the selected target.

The same points, two coordinate systems. Straight pixel-grid lines bend and spread in angular space. Pale amber segments are outside the trusted view. With an aligned camera, a centred target 3 m ahead is (0, 0, 3). Normalised image errors use the image centre; metric XYZ follows the calibrated optical axis and measured mount. Pixel indices stay u-right/v-down; outgoing XYZ uses x-right/y-up/z-forward. This is a model visualization, not a measured calibration.
